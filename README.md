# photo_editor

Это редактор фото — позволяет добавлять эффекты на фото.

## Функционал:
* Поворот изображения на 90° вправо и влево
* Отзеркалить
* Добавить резкость
* Перекрасить в черно-белый

## Поддерживаемые форматы:
* .jpg
* .jpeg 
* .png 
* .gif 
* .bmp

## Используемые библиотеки:
* os (Встроенный модуль)
* Pillow (PIL)
* PyQt5

## Инструкция по запуску проекта

### 1 Создание и активация виртуального окружения
```bash
python -m venv venv
source venv/bin/activate
```
### 2 Установка необходимых библеотек
```bash
pip install -r requirements.txt
```
### 3 Запуск проекта
```bash
python Editor.py
```
Примечание: Модифицированные фото сохраняются в папке Modified *папка создается в той же директории, где и находится оригинал изображения*


*Требуемая версия Python от 3.7 до 3.11*

*Этот проект направлен на широкий круг людей — проект дружелюбен к новичкам и не требует сложных навыков*
